# 工艺智控平台前端原型

依据《开发计划第一版.docx》制作的深色界面原型。双击 `index.html` 即可在浏览器打开，不需要安装依赖。

| 页面 | 适合的使用场景 | 视觉重点 |
| --- | --- | --- |
| 工艺总览 | 值班监控、集中展示 | 工艺流程、实时指标、告警和 AI 助手同屏 |
| 仿真推演 | 参数调整与方案评估 | 参数输入、基准对比、执行记录 |

桌面端通过左侧导航切换页面，窄屏端使用页首入口。设备节点可点击查看详情；AI 助手提供示例回答；仿真参数滑块和“运行仿真”提供演示交互。

所有设备、测点、指标和仿真结果均为**演示数据**。当前页面没有连接后端、真实知识库、机理模型或设备控制接口。运行仿真的计算仅用于表现交互流程。
